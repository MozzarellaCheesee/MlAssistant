# Справочник по коду

Здесь описан каждый модуль, класс, функция и настройка проекта: что делает, что принимает и возвращает, почему написано именно так. README в корне рассказывает, как запустить проект и какие решения приняты. Справочник нужен, чтобы читать и менять код.

Ссылки вида `app/application/assistant.py:93` указывают на строку в коде на момент написания.

## Как идёт запрос

1. Страница или голосовой цикл передают текст или аудио в `AssistantService` (`app/application/assistant.py`).
2. Аудио распознаёт GigaAM.
3. `GigaChatIntentParser` делит фразу на команды и разбирает каждую в интент: pydantic-модель из `app/application/intents.py`. Дату модель отдаёт выражением (`+1d`, `fri`, `12-15`), календарную дату считает `app/domain/dates.py`.
4. Обработчик интента меняет данные через порт `ItemRepository` и возвращает `Result` или `Question`.
5. `Question` сохраняется в состоянии диалога, следующий ответ пользователя дополняет черновик.
6. Ответ уходит текстом и, если включено, голосом Vosk.

Слои `domain` и `application` не импортируют FastAPI, GigaChat и SQLite. Это проверяет `tests/unit/test_architecture.py`.
